During the build (step 4):
  - The script runs Gradle + zipalign + apksigner itself ("bubblewrap build"
    fails on new Node versions with "spawn EINVAL").
  - apksigner asks for the KEYSTORE password, then the KEY password if they differ.

Keep project\android.keystore + both passwords safe (back up to a USB stick
or cloud drive). Every future update needs the same key and package ID.
